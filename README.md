Health Study Assignment

Inlämningsuppgift i kursen Pythonprogrammering och statistisk dataanalys.

Projektbeskrivning

I detta projekt analyseras ett hälsorelaterat dataset med hjälp av Python och statistiska metoder.

Syftet är att undersöka samband och skillnader i hälsodata samt att tillämpa statistiska metoder för att analysera och tolka resultaten.

Innehåll och analys

Projektet innehåller bland annat:

Deskriptiv statistik: medelvärde, median, minimum och maximum.

Datavisualisering med histogram, boxplot och spridningsdiagram.

Analys av andelen individer med sjukdom.

Simulering med NumPy.

Konfidensintervall med normalapproximation och bootstrap.

Hypotesprövning med Welch's t-test.

Simulering av statistisk styrka (power).

Dataset

Analysen använder health_study_dataset.csv.

Datasetet innehåller information om bland annat ålder, kön, längd, vikt, blodtryck, kolesterol, rökning och sjukdom.

Öppna health_study_analysis.ipynb i Jupyter Notebook eller Visual Studio Code.
